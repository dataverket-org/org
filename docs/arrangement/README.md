# Arrangement

Foredrag, møter og andre arrangement Dataverket deltar i eller arrangerer.

- **Én mappe per arrangement**, navngitt `ÅÅÅÅ-MM-DD-kort-navn`. Datoen først
  gjør at lista blir en tidslinje: det som har vært øverst, det som kommer nederst.
- `index.md` i mappa er arrangementssiden.
- Manus, lysbilder og vedlegg ligger i samme mappe, for eksempel `foredrag.md`.
- Bilder ligger i `bilder/`, med en `README.md` som sier hvem som har tatt dem.
