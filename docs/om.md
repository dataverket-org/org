{{< intro >}}
Dataverket er en organisasjon som jobber for at tilgang til kunnskap,
programvare og teknologi som er nødvendig for nasjonale, digitale
tjenester skal bli et felles gode.
{{< /intro >}}

## Visjon

Norsk næringsliv og offentlig sektor må kunne velge norsk og europeisk infrastruktur uten suverenitetstap. I dag står valget for de fleste mellom hyperscalere (gir suverenitet bort) eller selvbygget infrastruktur (uoverkommelig for de fleste). Dataverket bygger en tredje vei: en felles, åpen plattform som lar små og mellomstore norske leverandører tilby bare metal og KI-cluster på like vilkår.

Plattformen utvikles og vedlikeholdes i fellesskap. Hver enkelt leverandør beholder full kommersiell uavhengighet og egne kundeforhold; samvirket eier ikke kapasitet og selger ikke tjenester.

## Organisasjon

Dataverket er organisert i to deler med klart adskilte ansvar:

{{< columns count=2 >}}

{{< column >}}
### Samvirket

Driver økonomisk aktivitet til felles nytte for medlemmene. Utvikling, vedlikehold og tjenester gjennomføres som felles investeringer. Både offentlige og private aktører deltar på like vilkår, med demokratisk innflytelse over prioriteringene.

Samvirkemodellen er norsk og kjent gjennom samvirkelag og felleskjøp. Medlemmene deltar fordi det er lurt å gjøre jobben sammen.

[Se samvirkemodellen →](/samvirke/)
{{< /column >}}

{{< column >}}
### Stiftelsen

Den planlagte ideelle stiftelsen eier og vedlikeholder all kildekode åpent, uavhengig av enkeltmedlemmers interesser. Denne rollen er ideell og rendyrket: kunnskap og kode vi bygger opp skal forvaltes som et felles gode til nytte for samfunnet.

Stiftelsen er ennå ikke etablert. Etableringen følger samvirkets oppstart.
{{< /column >}}

{{< /columns >}}

## Tre medlemstyper

Felles for alle medlemmer er at de er *brukere* av plattformen, som er samvirkets økonomiske virksomhet.

{{< cards count=3 >}}

{{< card >}}
### Datasenter-leverandører

Eier rack, strøm, kjøling, nettverk og servere. Kjører Dataverket-plattformen på toppen og kan tilby suveren bare metal og KI-cluster til sine kunder.
{{< /card >}}

{{< card >}}
### Kunder

Velger fra en katalog, får dedikert leveranse fra én eller flere leverandører. Senere kan kundene få federert tilgang på tvers av leverandørene.
{{< /card >}}

{{< card >}}
### Privatpersoner

Lar engasjerte enkeltpersoner bidra med kompetanse og stemme uten å være tilknyttet en virksomhet. Andelsinnskuddet er bevisst lavt.
{{< /card >}}

{{< /cards >}}

## Arbeidsmåten

Plattformen, samvirkets vedtekter og dokumentasjonen utvikles i fellesskap og i åpenhet.

- **Kode**: utvikles på [kode.dataverket.org](https://kode.dataverket.org) som fri programvare.
- **Beslutninger**: dokumenteres som [Architecture Decision Records](https://docs.dataverket.org/decisions/), åpne og versjonerte.
- **Diskusjon**: åpen plattform på [diskusjon.dataverket.org](https://diskusjon.dataverket.org).
- **Forankring**: arkitekturen er bevisst forankret i nasjonale og europeiske rammeverk (NSM, Nkom, EU CSF, CRA, DFØ MPS).
