Det er flere måter å komme i kontakt med Dataverket på, alle åpne. Vi
foretrekker offentlige samtaler først, siden det vi diskuterer som
oftest er nyttig for andre også.

## Direkte kontakt

For ting som ikke passer i åpne kanaler. Typisk medlemskaps­forespørsler fra organisasjoner, eller spørsmål om personvern.

| Tema                      | Kontakt                              |
|---------------------------|--------------------------------------|
| Medlemskap som leverandør | medlem@dataverket.org                |
| Medlemskap som kunde      | medlem@dataverket.org                |
| Presse                    | post@dataverket.org                  |
| Sikkerhet og personvern   | sikkerhet@dataverket.org             |
| Generelt                  | post@dataverket.org                  |

E-postadressene over er foreløpige plassholdere mens samvirket etableres. Sjekk at den fungerer ved å sende en kort melding først.
